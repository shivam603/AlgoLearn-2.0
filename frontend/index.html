Sorting

Sorting Algorithms

Bubble Sort

What it is: A simple sorting method that swaps adjacent values until the array is ordered.

How it works: Repeated passes compare neighbors and bubble the largest unsorted value to the end.

Time: O(n²)

Space: O(1)

Selection Sort

What it is: A sorting algorithm that repeatedly chooses the smallest remaining element.

How it works: Each pass scans the unsorted section, selects the minimum, then swaps it with the next sorted position.

Time: O(n²)

Space: O(1)

Insertion Sort

What it is: A sorting algorithm that builds a sorted list one element at a time.

How it works: It takes the next unsorted value and inserts it into the correct position among the already-sorted values.

Time: O(n²)

Space: O(1)

Quick Sort

What it is: A fast divide-and-conquer sorting algorithm using a pivot.

How it works: It partitions the array around a pivot, then recursively sorts each partition.

Time: O(n log n)

Space: O(log n)

Merge Sort

What it is: A stable divide-and-conquer sort that merges sorted halves.

How it works: It recursively splits the array in half, sorts both sides, and merges them back together.

Time: O(n log n)

Space: O(n)

Heap Sort

What it is: A sort that uses a heap data structure to extract the next largest value.

How it works: It builds a max heap, then repeatedly removes the root and rebuilds the heap until sorted.

Time: O(n log n)

Space: O(1)
Search

Search Algorithms

Linear Search

What it is: A search algorithm that checks each value until it finds the target.

How it works: It scans the list sequentially, stopping when the target is found or the list ends.

Time: O(n)

Space: O(1)

Binary Search

What it is: A search algorithm for sorted lists that halves the search range each step.

How it works: It compares the target to the middle element, then continues in the lower or upper half.

Time: O(log n)

Space: O(1)
Graph

Graph Algorithms

Breadth-First Search

What it is: A graph traversal algorithm that visits nodes level by level.

How it works: It starts at a source node, explores all neighbors first, and uses a queue to track the next nodes to visit.

Time: O(V + E)

Space: O(V)

Depth-First Search

What it is: A graph traversal algorithm that explores as far as possible along each branch before backtracking.

How it works: It starts at a source node and follows one path to the end, using a stack or recursion to return and explore remaining branches.

Time: O(V + E)

Space: O(V)

Kruskal's Algorithm

What it is: A graph algorithm that builds a minimum spanning tree by selecting edges in weight order.

How it works: It sorts edges by weight and adds each edge unless it creates a cycle.

Time: O(E log E)

Space: O(E)

Dijkstra's Algorithm

What it is: A graph algorithm for finding shortest paths from one node to all others in a weighted graph.

How it works: It repeatedly picks the nearest unvisited node, then updates distances to its neighbors.

Time: O(E + V log V)

Space: O(V)
