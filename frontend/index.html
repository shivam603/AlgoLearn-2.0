Sorting Algorithms (6)

Launch Sorting Engine

Bubble Sort

O(n²)

Repeatedly compares and swaps adjacent elements until the largest values bubble to the top.

Theory & Code Animate

Selection Sort

O(n²)

Finds the minimum element from the unsorted section and places it at the sorted boundary.

Theory & Code Animate

Insertion Sort

O(n²)

Builds a sorted array one element at a time by shifting elements into their proper positions.

Theory & Code Animate

Quick Sort

O(n log n)

High-performance divide-and-conquer algorithm partitioning arrays around a pivot element.

Theory & Code Animate

Merge Sort

O(n log n)

Stable divide-and-conquer sorting that recursively divides arrays and merges sorted halves.

Theory & Code Animate

Heap Sort

O(n log n)

Utilizes a max-heap data structure to repeatedly extract the maximum root element in place.

Theory & Code Animate

Graph Suite

Graph & Shortest Path Algorithms (4)

Launch Graph Engine

BFS

O(V+E)

Level-order graph traversal using a queue, ideal for shortest paths in unweighted graphs.

Theory Animate

DFS

O(V+E)

Deep path graph traversal using recursion/stacks, ideal for maze solving and cycle checks.

Theory Animate

Kruskal's

O(E log E)

Greedy algorithm building minimum spanning trees by picking minimum edge weights without cycles.

Theory & Code

Dijkstra's

O(E+V log V)

Finds the single-source shortest path across weighted graphs with non-negative edge costs.
